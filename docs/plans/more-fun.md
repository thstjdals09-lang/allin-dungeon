## Task 2: 상대도 벳·레이즈·블러프

지금 상대는 콜/폴드만 한다. 거리(플롭·턴·리버)마다 상대도 행동하게 한다.
- logic.js 에 `enemyAct(enemy, v, facing, rng)` 추가. `v` = 상대 패 세기(strength), `facing` = 'none'(내가 체크) | 'bet'(내가 벳). 반환:
  - facing 'none': v ≥ 0.62 이면 'bet', 아니면 rng() < enemy.bluff 이면 'bet'(블러프), 아니면 'check'.
  - facing 'bet': enemyFolds 로 폴드 판정이 먼저(기존 함수 그대로), 폴드가 아니면 v ≥ 0.85 이고 rng() < 0.5 이면 'raise', 또는 rng() < enemy.bluff × 0.3 이면 'raise'(블러프 레이즈), 나머지는 'call'.
  - 올인을 받으면 지금처럼 콜/폴드만(레이즈 없음).
- ENEMIES 에 `bluff` 값: 허세꾼 0.35, 카드 마술사 0.3, 빚더미 노름꾼 0.25, 보스 3명 0.15, 나머지 0.1. pickEnemy 기본값 bluff: 0.1.
- 흐름: 내가 체크 → 상대가 'bet' 이면 팟 +1 하고 "상대 벳" 상태가 된다. 이때 내 선택: 폴드 / 콜(팟 그대로, 다음 거리) / 레이즈(팟 +1 → 상대는 enemyFolds 로 폴드 판정, 아니면 콜) / 올인(팟 +ALLIN_ADD → 콜·폴드).
  내가 벳 → 상대 'raise' 면 팟 +1 하고 "상대 레이즈" 상태: 폴드 / 콜만.
  거리마다 레이즈는 한 번까지.
- 폴드 비용: 내가 상대 벳·레이즈에 폴드하면 `ANTE × (상대가 올리기 전 팟)` 을 잃는다. 상대 폴드는 지금처럼 `ANTE × 지금 팟`.
- 텔은 지금처럼 strength + lie 로. 블러프 벳일 때도 텔은 실제 세기를 따른다(그래서 텔이 단서가 된다).
- 화면: 상대 벳·레이즈를 받으면 보드 위에 "상대 벳 · 팟 ×N" 표시, 칩 버튼은 폴드·콜·레이즈·올인(레이즈를 받았으면 폴드·콜). 기록에 "턴 체크 → 상대 벳" 같은 줄.
- 연출: fx 이벤트 `ebet`(상대 메달에서 팟으로 칩이 날아감, 효과음 chip). `raise` 도 같은 연출.
- test.js: enemyAct 단위 테스트(고정 rng 로 bet/check/raise/call/fold 각각). `--sim` 봇이 상대 벳에 응답하도록(내 패가 원페어 이상이면 콜, 아니면 텔이 '여유'면 폴드, 그 밖엔 콜) 고친다.
- 밸런스 목표: `node test.js --sim` 에서 1층 일반 상대 평균 받는 피해 25 이하(시작 스택 80). 넘으면 ENEMIES 의 mul 이나 bluff 를 조정하고 결과 표를 보고서에 붙인다.

## Task 3: 보스·하이롤러 고유 규칙과 예고

상대 정보에 `rule` 을 넣고, 판이 시작될 때 상대 패널에 "예고" 한 줄을 보여 준다(텔 아래, 예: "예고 · 이번 판 강제 올인").
- 문지기 곰 `forceAllin`: handNo 가 3의 배수인 판은 플롭에서 상대가 올인한다. 내 선택은 폴드 / 콜(팟 +ALLIN_ADD, 남은 카드 깔고 쇼다운)만. 예고: 그 판이면 "이번 판 강제 올인", 아니면 "N판 뒤 강제 올인".
- 수석 크루피어 `rigBoard`: 내가 핸드를 확정한 직후, 남은 테이블 덱 위 3장 중 상대 strength 를 가장 높이는 카드로 보드 1장(플롭 중 상대에게 가장 쓸모없는 카드)을 바꾼다. 예고 "핸드를 정하면 보드 1장을 바꿔친다". 연출: 바뀐 보드 카드가 뒤집히며 들어옴(기존 deal 연출로 충분).
- 하우스의 주인 `hiddenCard`: 리버 카드가 쇼다운 전까지 엎어져 있다(보이는 건 뒷면). 내 패 미리보기·이기면 얼마도 숨은 카드를 빼고 계산. 예고 "리버는 쇼다운까지 엎어져 있다".
- 떠돌이 딜러 `stealChange`: 판마다 내 체인지 −1(0 아래로는 안 감). 예고 "체인지 1개를 빼앗는다".
- 카드 마술사 `swapRandom`: 핸드 확정 직후 플롭 1장을 무작위로 바꾼다. 예고 "핸드를 정하면 보드 1장이 바뀐다".
- 큰손 `bigPot`: 팟이 ×2 에서 시작. 예고 "팟 ×2 로 시작".
- 상대 특성 시트(views.js enemy)에 규칙 설명 한 줄 추가.
- logic.js 에 규칙 도우미(예: `rigCard(ehole, board, candidates)` 가 바꿀 위치와 카드를 돌려줌)와 테스트.

## Task 5: 이벤트를 16개로, 대가 있는 선택

events.js 의 이벤트를 16개 이상으로 늘린다. 각 이벤트는 선택지 2~3개 + "그냥 간다". 효과는 바로 적용되는 것과 덱 시트(고르기 → 확인)를 여는 것. 새로 넣을 이벤트(이름·글은 다듬어도 됨, 수치는 그대로):
1. 사채 창구: 상금 +80 / 최대 스택 −8.
2. 피의 계약서: 스택 −15 → 무작위 유물 1개.
3. 카드 도둑: 덱에서 무작위 카드 1장을 잃고 상금 +40 / 거절.
4. 거울 방: 카드 1장 복제(덱 시트) 대가 스택 −6.
5. 낡은 슬롯머신: 상금 20 넣기 → 1/3 확률 상금 +70, 아니면 아무것도 없음.
6. 연습 테이블: 이번 층 동안 판마다 체인지 +1 대가 상금 −30.
7. 응급실: 상금 40 → 스택 +25.
8. 문신 가게: 카드 1장에 고르는 강화(강화 6종 중 무작위 2개 제시) 대가 상금 −35.
9. 정보원: 상금 25 → 이번 층 보스가 누구인지와 규칙을 알려 줌(지도 위에 표시).
10. 뒷골목 내기: 스택 −10 → 상금 +60.
11. 카드 합치기: 같은 숫자 카드 2장을 골라 하나로 합치면 숫자 +2(최대 A).
나머지는 기존 5개. 이벤트 등장은 같은 판에서 반복되지 않게(본 이벤트 id 를 S 에 기억).

## Task 7: 복기와 밸런스

- 복기: 판이 끝나면(쇼다운·폴드) "플롭 때 내 승률 N%" 를 계산해 결과 줄 아래에 보여 준다. 상대 핸드를 아는 상태에서 남은 턴·리버를 전부 세어(완전 열거) 승·무·패 비율을 구한다(logic.js `equityAtFlop(hole, ehole, flop, deadIds)`; 숨은 카드 규칙과 상관없이 실제 카드로). 한 줄 평:
  - 내가 폴드했는데 승률 ≥ 50% → "폴드가 아까웠다"
  - 내가 벳·레이즈·올인·콜로 끝까지 갔는데 승률 < 25% → "무리했다"
  - 그 밖 → 표시 없음.
  기록 시트에 "아까운 폴드 N번 · 무리한 승부 N번" 누적.
- 밸런스: Task 2~6 이후 `node test.js --sim` 봇을 상대 벳·보스 규칙에 맞춰 돌리고, 1층 일반 평균 피해 ≤ 25, 1층 보스 ≤ 45, 3층 보스 ≤ 90(시작 스택 80, 유물 없음 기준)이 되게 ENEMIES 수치를 조정. 결과 표를 보고서에.
- test.js: equityAtFlop 단위 테스트(이미 이긴 경우 100%, 진 경우 0% 등).
